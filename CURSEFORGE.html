Never lose your mouse position in menus again.

Seamless Cursor provides smooth, persistent mouse cursor positioning for Minecraft menus, container updates, and server chest GUIs.

What is Seamless Cursor?

When playing on servers like Hypixel (SkyBlock, Bedwars, SkyWars) or interacting with server menus, clicking through chest GUIs is often frustrating:

  • Every time a menu changes pages, updates items, or transitions to a sub-menu, vanilla Minecraft snaps your mouse cursor back to the exact center of the screen.
  • During that brief transition packet, your camera can jerk and your cursor hitches.

Seamless Cursor fixes this completely.

Your mouse stays exactly where you left it — right on the slot or button you were interacting with. Transitions feel completely instant, smooth, and natural, as if nothing closed at all.

Features

  • No Center Snapping: Your cursor never resets to the center during menu transitions or reopening.
  • Zero Mouse Hitching: Eliminates the brief cursor stutter and camera jitter when server plugins refresh chest screens.
  • Pure Client-Side: Requires NO server-side mod. Works on any multiplayer server.
  • Safe Bounds Clamping: Automatically clamps coordinates within window limits if window dimensions change.
  • Ultra Lightweight: Zero external dependencies (doesn't even require Fabric API). Under 45 KB jar size!
  • Zero-Config: Plug-and-play. Drop it into your mods folder and it works immediately without any setup.

Is it Safe? (Anticheat & Server Rules)

Yes, 100% Ban Safe.

  • Zero Network Packets: The Minecraft network protocol does not transmit mouse cursor coordinates to servers. Servers only receive slot click events when you manually click.
  • No Automation / No Macros: Seamless Cursor does not click for you. All clicks remain 100% manual.
  • Client-Side Cosmetic QoL: Fully compliant with Hypixel's "Allowed Modifications - Aesthetic & GUI Improvements" guidelines (identical to cursor memory features found in Badlion Client and Lunar Client).

Installation

  1. Install Fabric Loader.
  2. Download seamless-cursor-1.0.0.jar.
  3. Place the .jar file into your .minecraft/mods folder.
  4. Launch Minecraft and enjoy seamless menus!
